## 今日實際使用的 Prompt

1. 現在這個模式不錯，新增完它會去前端網頁嗎？我想問我可以把 GA4 這個外部分析工具分析出來的結果同步顯示在我們後台嗎？或是怎麼顯示不會讓我伺服器掛掉
2. 好的，那你幫我做一版我先看一下 GA4 效果怎麼樣
3. 繼續
4. 所以你剛剛前面說的每半小時或是一小時刷新一次後台數據要怎麼用？
5. 那我想知道如果這樣用這些資料要存資料庫嗎？
6. 可以先幫我寫一份 `.md` 檔晚點我再來確認
7. 根據你的專業你會建議我後台還可以優化或是進階那些功能？你的建議都要幫我寫在 Excel 內，修改也要登記什麼時候修正的
8. 那你現在建議從哪邊開始？
9. 先幫我做簡單可以快速看到成效的
10. 我想問一下其他欄位的功能可以優化嗎？因為我覺得不夠人性化
11. 幫我登記進去一併修改，前端還有可以今天改的進度嗎？如果日期尚有重疊我希望可以每個日期修改哪一部分都幫我寫一下
12. 我想問一下這個，RWD 照理來說字體會自動換行？還是會自行讓字體變小
13. 會建議我怎麼做？
14. 根據你建議地幫我調整，要幫我記錄
15. 還有什麼可以再繼續調整的嗎？
16. 好的幫我處理
17. 辛苦了，幫我寫今天使用那些 prompt

## 整理後可重用 Prompt

### 1. GA4 後台同步規劃

```text
請幫我評估把 GA4 分析資料顯示在後台的做法，重點回答：
1. 是否建議直接即時打 GA4 API
2. 是否要存資料庫
3. 建議多久同步一次
4. 怎麼做才不會讓伺服器負擔過重
5. 請依照我目前專案結構提出建議
```

### 2. 先做一版 GA4 後台畫面

```text
請先幫我做一版 GA4 後台分析頁預覽，先用 mock data，不要直接串真的 GA4 API。
我想先看畫面效果，再決定正式串接方式。
```

### 3. 產出規劃文件

```text
請把 GA4 後台同步方案整理成一份 .md 文件，內容包含：
- 是否需要存資料庫
- 建議同步頻率
- 觸發方式
- 資料表建議
- API 架構建議
- 風險與結論
```

### 4. 後台優化建議加進 Excel

```text
請根據你的專業，列出後台還可以優化或進階的功能。
所有建議都要寫進 Excel，並且之後只要有修改，就要記錄修正日期與修正內容。
```

### 5. 先做快速看得到成效的版本

```text
請先做簡單但能快速看出成效的優化版本，直接實作，不只給我建議。
做完也要同步更新 Excel 紀錄。
```

### 6. 表單欄位人性化優化

```text
請幫我優化這個後台表單，方向是更人性化：
- 欄位名稱更白話
- 補範例與提示
- 加合理預設值
- 錯誤訊息說清楚怎麼改
- 如果有修改要同步登記到 Excel
```

### 7. 同一天修改要分開記錄

```text
如果今天有多個修改項目，請不要只寫同一天日期，
還要分別寫清楚每個日期到底修改了哪一部分，並同步更新 Excel 摘要。
```

### 8. RWD 標題調整

```text
請依照你的建議幫我調整這個頁面的手機版標題，
不要讓最後一個字單獨掉行，
要兼顧字級、換行與可讀性，
而且要幫我記錄到 Excel。
```

### 9. 空狀態頁面優化

```text
請繼續優化這個空狀態頁，
包含上方留白、說明文字寬度、和 footer CTA 的銜接，
如果適合也可以補一個替代行動入口，
並把這次修改獨立登記到 Excel。
```
