# iFare RWD 回歸檢查清單

更新日期：2026-05-19

這份清單用於 UI/UX 調整、部署前驗收與遠端主機 smoke test。每次改動版面、表格、表單、圖表、首頁或前台內容頁時，至少跑一次桌機、平板、手機三組 viewport。

## 固定 Viewport

| 類型 | 尺寸 | 重點 |
| --- | --- | --- |
| 桌機 | 1440 x 900 | 主要後台工作情境、雙欄編輯與預覽 |
| 小桌機 | 1280 x 800 | Sidebar 展開時內容是否被擠壓 |
| 平板橫向 | 1024 x 768 | Dashboard、表格、圖表是否提早切欄 |
| 平板直向 | 768 x 1024 | 表單欄位、篩選列、卡片是否可讀 |
| 手機大 | 430 x 932 | iPhone Pro Max 類型，檢查按鈕與固定元素 |
| 手機小 | 375 x 667 | 長文字、CTA、表格空狀態與 footer |

## 後台檢查

- `PageManagement` 新增/編輯頁：桌機、平板、手機預覽切換不互相擠壓。
- `PageManagement` 圖片上傳：上傳、儲存、前台顯示都可完成。
- `CardSearchParam`：日期、下拉、文字搜尋與清除條件不造成版面跳動。
- `CardTable`：表格空狀態、分頁大小切換、刪除確認彈窗在手機寬度不溢出。
- `Analysis_DashboardView`：filter bar、KPI、ApexCharts 在 1024px 以下切單欄。
- `LoginView`：登入卡片、錯誤提示、Caps Lock 提示不遮住按鈕。
- `NoPermission`：提示文案與返回按鈕在手機上可點擊。

## 前台檢查

- 首頁 hero：主 CTA 在首屏可見，文字不壓到導覽列。
- `ifare` 搜尋頁：篩選器、熱門/最近搜尋、錯誤提示在手機不截斷。
- `ifare/result`：篩選列、結果卡片、空狀態在手機垂直堆疊。
- `ifare/info`：福利詳情、文件清單、相關政策區塊不互相重疊。
- 動態頁：hero、文字段落、圖文並列、CTA 區塊在手機上下間距正常。
- Header/Footer：手機選單、社群按鈕、客服浮動按鈕不遮住主要 CTA。

## 驗收標準

- 文字沒有被截斷成難以閱讀的單字或逐字直排。
- 按鈕高度至少接近 44px，手機上可點擊。
- 表格、圖表、圖片不超出 viewport 寬度。
- 固定或浮動元素不遮住表單按鈕、聊天入口或 footer 連結。
- 切換分頁大小、篩選條件、裝置預覽時版面不跳動到不可操作狀態。
- 圖片載入失敗時有可理解的 fallback 文案或 alt。

## 部署前 Smoke Test

- 後台登入成功。
- 後台頁面管理新增一頁並儲存。
- 上傳一張圖片，前台動態頁可顯示。
- 前台首頁、福利查詢、福利詳情、最新消息各開一次。
- 手機 viewport 檢查 header menu、footer、客服入口。
- `npm run build` 通過後再部署。
