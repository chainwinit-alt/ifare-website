# iFare_Frontend（前台官方網站）

Nuxt 3 前台。啟動方式與專案總覽見 repo 根目錄 `README.md`；
系統設計、部署與 API 的完整說明見 `docs/iFare_系統文件.docx`（來源：`docs/src/iFare_系統文件.md`）。

搜尋與 AI 品質的測試工具在 `scripts/` 底下，各有自己的 README：

- `scripts/llm-qa-bench/` — AI 摘要問答模型測試（含資格紅線與編造檢測）
- `scripts/search-eval/` — 搜尋品質評估（固定題組計分）
- `scripts/search-relevance/` — 主題落地檢查回歸（search-suite／gate-sim）
